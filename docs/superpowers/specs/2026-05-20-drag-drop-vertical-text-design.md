# 排版小工具 — 拖拽加载图片 + 横竖排文字 + 去导出框 设计文档

- 日期：2026-05-20
- 范围：在 paiban-tool v0.1.0 基础上新增两个功能并修复一个导出 bug
- 状态：已与用户确认设计，待写实现计划

## 背景

排版小工具用于在底图上叠加文字框、导出 PDF（主用途：祈福牌位、请柬、奖状批量模板）。
本次三项改动：

1. 拖拽图片到窗口即可加载底图（替代只能点"选择图片…"）
2. 文字框支持横排 / 竖排两种排版方向
3. 修复：导出 PDF / 打印时文字框带一圈浅色框

## 已锁定的设计决策

- **竖排形态**：真竖排 —— 每个字保持正立，从上往下排；多行（回车换行）时新列往**左**（传统右起）。不是整段旋转 90°。
- **竖排类结构**：方案 A —— 单个 `TextBoxItem` 加 `direction` 属性（`'horizontal'` / `'vertical'`），不新建独立类。理由：横↔竖切换只翻标志位，文字/位置/字体保留可即时预览；右侧面板、模板存档、PDF 导出无需区分类型。
- **竖排编辑方式**：选项 1 —— 竖排文字框双击时弹出普通横排输入框编辑；横排文字框保持现有的就地编辑。理由：Qt 无原生竖排编辑器，自做竖排光标 bug 风险高且不值得。

## 改动一：拖拽加载图片

**目标**：拖任意图片文件到窗口任意位置 → 加载为底图，行为等同点击"选择图片…"。

**做法**：
- 在 `MainWindow` 开启拖放（`setAcceptDrops(True)`），实现 `dragEnterEvent` / `dragMoveEvent` / `dropEvent`。
- `dragEnterEvent`：`mimeData` 含本地文件 URL 时接受拖入。
- `dropEvent`：取第一个图片文件加载；拖入多个文件取第一张图片；非图片文件给出提示（`QPixmap.isNull()` 已能判定）。
- 把 `open_image()` 中"拿到路径之后"的加载逻辑抽成 `load_image_from_path(path)`，文件对话框流程和拖放流程共用，消除重复。

**涉及文件**：`src/main_window.py`

## 改动二：横排 / 竖排文字

**目标**：每个文字框可独立设为横排或竖排。

**UI**：右侧"文字框样式"面板新增一组「横排 / 竖排」切换按钮（样式复用现有 A4 横向/竖向 toggle 按钮）。选中文字框时按钮反映其当前方向。

**竖排行为**：
- 字正立、从上往下排；文字内按回车换行 → 新起一列往左。
- 竖排文字框按内容自适应大小，**不做**按框大小自动折行（列数由回车显式控制，模板工具行为需可预测）。
- 竖排模式下不显示右下角缩放手柄。
- 字体、字号、加粗、斜体、颜色、行高（竖排下=字间距）均生效。
- 「对齐」按钮在竖排时置灰（左/中/右对竖排无意义）。
- 双击竖排文字框 → 弹出 `QInputDialog` 多行输入框编辑文字。

**实现要点（`canvas.py` 的 `TextBoxItem`）**：
- 新增 `self._direction`，默认 `'horizontal'`；`set_direction(d)` 切换时调 `prepareGeometryChange()` + `update()`。
- `paint()`：横排走 `super().paint()` + 现有装饰；竖排时**不**调 `super().paint()`，改为用 `QPainter.drawText()` 逐字绘制——每列按 `\n` 切分，列从右往左排，列内字从上往下排。字符尺寸/间距用 `QFontMetricsF` 计算（单元格近似方形，每个字在单元格内水平居中）。
- `boundingRect()`：横排用 `super()`；竖排按列数 × 列宽、最长列字数 × 行高计算。
- 竖排模式 `setTextInteractionFlags(NoTextInteraction)` 恒定关闭就地编辑。
- 文字仍存在 `QTextDocument` 里（`toPlainText()` 取字符），渲染为自定义绘制。
- `to_dict()` / `from_dict()` 新增 `direction` 字段；老模板无此字段时默认 `'horizontal'`，向后兼容。

**PDF 导出**：`pdf_export.py` 的 `scene.render()` 会自动调用每个文字框的 `paint()`，竖排同样矢量输出，导出代码无需改。

**涉及文件**：`src/canvas.py`、`src/side_panel.py`、`src/main_window.py`

## 改动三：去掉导出/打印时的浅色框

**根因**：`canvas.py` 中 `TextBoxItem.paint()` 在文字框未选中时画一圈蓝色虚线边框。`pdf_export.py` 导出前会取消所有文字框的选中状态，于是导出/打印时每个框都落到"未选中"分支画出该边框。该虚线框本是屏幕上的位置辅助线，不应进 PDF。

**做法**：
- `TextBoxItem` 新增 `_export_mode` 标志（默认 `False`）。
- `pdf_export.py` 在 `scene.render()` 前把所有文字框 `_export_mode` 置 `True`，渲染后复位（与现有"备份/恢复选中状态"放同一处）。
- `paint()` 在 `_export_mode` 为真时跳过全部辅助装饰（虚线框、选中橙框、缩放手柄），只画文字（横排）或只画竖排字符。
- 屏幕上的虚线框保留，仅导出时不画。

**涉及文件**：`src/canvas.py`、`src/pdf_export.py`

## 明确不做（MVP 范围外）

- 竖排标点（，。：等）的传统位置偏移
- 竖排中数字/字母旋转成横向（本设计中数字逐字正立堆叠，如"2026"竖排）
- 竖排按框高自动折行

## 验证方式

- Mac 上 `cd src && python3 main.py` 运行：
  - 拖一张图进窗口 → 底图加载成功；拖非图片文件 → 有提示。
  - 新建文字框切竖排 → 字正立从上往下；输入含回车的文字 → 新列往左。
  - 双击竖排框 → 弹输入框可改字。
  - 竖排框选中时对齐按钮置灰、无缩放手柄。
  - 导出 PDF → 打开 PDF 确认文字框**无**浅色边框，且竖排文字正常显示。
- 加载一个 v0.1.0 老模板（无 `direction` 字段）→ 不报错，按横排显示。
